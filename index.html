I'm Jana Ahmed Farahat — a Data Science & AI specialist with a strong foundation in machine learning, data analytics, and software engineering. I'm passionate about turning messy, complex data into clear insights and practical, intelligent solutions.

My journey started with a deep love for problem-solving. I've tackled 150+ algorithmic challenges on Codeforces and HackerRank, which sharpened my analytical thinking and ability to write efficient, clean code.

On the professional side, I interned at the National Bank of Egypt (NBE) where I cleaned real-world banking records, wrote SQL queries to build a Customer 360 view, and delivered an interactive Power BI dashboard for executive reporting. I also completed certified Generative AI training through CIB in partnership with CFA Institute, CISI, SAS, and IFC — and I'm currently part of the DEPI Data Science & AI track, working on end-to-end machine learning pipelines.

Beyond data, I've built full-stack web applications, implemented C++ data structures from scratch, and created AI tools like a resume matcher powered by TF-IDF and Cosine Similarity. I enjoy working across the full stack — from raw data pipelines to polished user-facing products.

I'm now available for freelance projects in machine learning, data analysis, Power BI dashboards, Python automation, and web development. If you have a data problem that needs solving, I'd love to work on it.
